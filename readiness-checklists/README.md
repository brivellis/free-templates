# Readiness Checklists (free) — v1.0

Four single-file self-assessment workbooks. One requirement or outcome per row, with the evidence an auditor usually asks for, a status, a 0–3 maturity score, an owner, the evidence location, a due date, built-in checks, a summary with % ready per group and a heat map, and a link to the free Brivellis kit file that helps close each gap. No GRC tool needed.

## What's inside
- `Brivellis_Readiness_Checklist_ISO20000-1_v1.0.xlsx` — Readiness Checklist for ISO/IEC 20000-1 (2018 + Amd 1:2024): 44 rows, clauses 4 to 10.
- `Brivellis_Readiness_Checklist_ISO27001-2022_v1.0.xlsx` — Readiness Checklist for ISO/IEC 27001:2022 (+ Amd 1:2024): 25 clause rows and 93 Annex A control rows.
- `Brivellis_Readiness_Checklist_ISO22301_v1.0.xlsx` — Readiness Checklist for ISO 22301 (2019 + Amd 1:2024): 46 rows, clauses 4 to 10.
- `Brivellis_Readiness_Checklist_NIST-CSF-2.0_v1.0.xlsx` — Readiness Checklist for NIST CSF 2.0: all 106 Subcategory outcomes, quoted from NIST CSWP 29 with attribution (text and order as in the NIST CSF 2.0 Reference Tool export, Final).

Each workbook has five tabs: Read Me, Document Control, Checklist, Summary (heat map), AI Prompt.

ISO rows give the clause or control number and a Brivellis description in our own words, never the title or the text of the standard: read each requirement in your licensed copy. NIST outcome text is quoted from NIST CSWP 29, a US government publication; no NIST endorsement is claimed.

## How to use it
1. Fill in Document Control.
2. On the Checklist tab, set Status and Maturity for each row, and record the owner, where the evidence is kept and a due date for any gap.
3. Fix every row whose Check column turns red.
4. Read the Summary tab for % ready per group and the heat map.
5. Follow the Next step link to the free kit file that helps close the gap.

## AI use
The last Checklist column holds a ready-made prompt: "draft an evidence note from what you paste". Its output is a DRAFT for a person to check. It never sets Status or Maturity, and no formula reads AI output. Rules are on the AI Prompt tab.
